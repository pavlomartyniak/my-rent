# Скарги й блокування

Вимога App Store 1.2 (контент користувачів): користувач може поскаржитись на оголошення, користувача й повідомлення,
заблокувати користувача, а ми реально обробляємо скарги й публікуємо контакт.

## Що бачить користувач
- **Оголошення**: внизу сторінки «Поскаржитись на оголошення» і «Заблокувати власника».
- **Чат**: меню «···» у заголовку (скарга на користувача, блокування); довге натискання на чуже повідомлення (скарга на повідомлення).
- **Налаштування**: «Заблоковані користувачі» (розблокування), «Написати нам» (kolo.rentapp@gmail.com).
- У «Умовах користування» (розділ 3) описано скарги, блокування й строк розгляду: 24 години.

## Що робить блокування
Сторони (в обидва боки) не бачать оголошень та заявок одне одного й не можуть писати в чаті, надсилати запити чи пропозиції.
Чинні угоди й договори не скасовуються.

## Як розглядати скарги
Кожна нова скарга приходить листом на `MODERATION_EMAIL` (за замовчуванням kolo.rentapp@gmail.com). Далі з папки `backend`:

```bash
npm run moderate -- reports                          # відкриті скарги (--all: усі)
npm run moderate -- hide-listing <carId>             # приховати оголошення
npm run moderate -- suspend <email|userId>           # призупинити акаунт (вхід закрито, оголошення приховано)
npm run moderate -- resolve <reportId> "що зроблено" # позначити розглянутою
```

Для продакшену: `APP_ENV=production npm run moderate -- <команда> --yes`. Без `--yes` зміни в проді не виконуються.
Зняти: `unhide-listing <carId>`, `unsuspend <email|userId>`.

Призупинений акаунт втрачає доступ до API протягом хвилини (кеш), навіть якщо токен ще дійсний.
